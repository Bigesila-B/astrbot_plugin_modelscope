# astrbot_plugin_modelscope

AstrBot 插件 —— 调用 [魔搭社区 ModelScope](https://modelscope.cn) API-Inference 实现文生图、图编辑与自定义预设工作流。

> 独立插件，与原 Grsai 插件互不影响，可同时安装。支持 Krea-2-Turbo、Z-Image-Turbo、Qwen-Image、Qwen-Image-Edit、FLUX.1、Stable Diffusion 3.5 等模型。

## 功能一览

| 功能 | 说明 |
|------|------|
| **文生图** | 发送触发词 + 提示词，调用魔搭生图模型生成图片 |
| **图编辑** | 发送触发词 + 提示词 + 图片，基于原图进行编辑（需使用支持编辑的模型，如 Qwen-Image-Edit） |
| **自然语言生图** | 可开启聊天 LLM 工具调用，分别指定默认文生图和图生图模型 ID，无需触发词 |
| **自定义预设** | 通过视觉语言模型（LLM）分析图片自动生成改图提示词，再调用生图模型出图 |
| **多模型配置** | 可同时配置多个生图模型，每个模型使用独立的触发词、API、参数 |
| **图片比例** | 支持自定义比例（中英文冒号均可），自动按短边 1024 转为像素 size 传给魔搭；也支持直接输入像素值（如 1024x1024） |
| **负向提示词** | 每个模型可单独配置负向提示词（魔搭原生支持） |
| **QQ 引用图片** | 支持将 QQ 引用消息中的图片作为图编辑输入 |
| **预设附加文本** | 在预设触发词后空格输入文字，会附加到预设提示词末尾一起发给语言模型 |

## 依赖

无需额外安装依赖。`Pillow` 与 `aiohttp` 均由 AstrBot 核心自带，本插件直接使用。

## 配置说明

在 AstrBot WebUI 的「配置」→「插件配置」中设置，共四部分：

### 1. 默认图片比例 `aspect_ratio`

用户未指定比例时的全局默认值。支持比例（如 `1:1`、`16:9`）或像素值（如 `1024x1024`）。默认 `1:1`。

> 比例会自动按短边 1024 推算并对齐到 8 的倍数，例如 `2:3` → `768x1152`，`16:9` → `1024x576`。可在模型配置中修改 `size_base` 为 2048 以生成更高分辨率（需模型支持，如 Krea-2）。

### 2. 生图模型配置 `models`（可添加多个）

点击 `+` 添加模型。每个模型条目包含：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `trigger_t2i` | 文生图触发词 | `魔搭生图` |
| `trigger_i2i` | 图编辑触发词 | `魔搭改图` |
| `url` | API 基础地址，固定为 `https://api-inference.modelscope.cn`，留空则使用默认 | `https://api-inference.modelscope.cn` |
| `apikey` | 魔搭社区 Access Token，以 `ms-` 开头 | 空 |
| `model_id` | 模型 ID，如 `krea/Krea-2-Turbo` | `krea/Krea-2-Turbo` |
| `negative_prompt` | 负向提示词（可选），如 `lowres, bad anatomy, text, watermark` | 空 |
| `size_base` | 短边基础像素。按比例生成时的短边基准，如设为 `2048` 则 `1:1`→`2048x2048`、`2:3`→`2048x3072`。Krea-2 等模型支持 2048；部分模型仅支持 1024，设过高会被服务端拒绝 | `1024` |
| `poll_timeout` | 任务轮询超时秒数，魔搭为异步任务，插件每 3 秒轮询一次 | `180` |

> **多模型示例**：模型 A 用触发词「魔搭生图 / 魔搭改图」走 `krea/Krea-2-Turbo`；模型 B 用「千问生图 / 千问改图」走 `Qwen/Qwen-Image-Edit` 用于图编辑。

### 3. 自然语言生图（新增）

先在上方「生图模型配置」中添加模型并填写 API Key，再设置以下三项：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `enable_natural_language` | 允许自然语言触发 LLM 生图 | 关闭 |
| `natural_language_t2i_model_id` | 默认文生图模型的完整 `model_id`，填写上方已有配置中的模型 ID | 空 |
| `natural_language_i2i_model_id` | 默认图生图模型的完整 `model_id`，须选择支持图编辑的模型 | 空 |

例如，上方配置了 `krea/Krea-2-Turbo` 和 `Qwen/Qwen-Image-Edit` 两个模型，就分别把这两个 ID 填入文生图和图生图输入框。这里填写的是模型 ID，不是触发词，也不是聊天 LLM 的名称。插件会复用对应模型配置中的 API 地址、密钥、负向提示词、分辨率和轮询超时，不需要再填一套密钥。同一个模型 ID 配置了多次时使用第一项。

保存配置并重载插件后，确保 AstrBot 当前聊天模型支持工具调用（Function Calling），且对应的人格/会话工具配置中已启用 `modelscope_text_to_image` 和 `modelscope_image_to_image`。自然语言意图由 AstrBot 当前聊天 LLM 判断，不使用预设里的独立 LLM 配置，也无需为此另填 LLM API。

示例：

- 文生图：`帮我画一只坐在窗边的橘猫，水彩风格，横屏 16:9。`
- 图生图：发送图片或引用一条含图片的消息，然后说 `帮我把这张照片改成油画，保留人物和构图。`

关闭开关时，两项生图工具会从本次 LLM 请求中移除，工具执行入口也会拒绝调用。某类默认模型 ID 留空、未匹配到已有模型或缺少 API Key 时，仅该类工具不可用，启动日志会给出配置原因；不会自动改用第一个模型。可只配置文生图或只配置图生图。原有触发词和预设继续使用原来的路由规则。

图生图只读取本条消息或引用消息中的第一张图片，未指定比例时沿用原图最接近的支持比例；纯文生图未指定比例时使用全局默认比例。单独在历史聊天中发过图片但本条未附图/引用时，请重新附图或引用。仅分析图片或讨论绘画不会被要求调用生图工具，是否调用仍由聊天 LLM 决定。

工具调用的等待时间应覆盖生图耗时；若 AstrBot 的「工具调用超时」小于模型的 `poll_timeout`，请适当调大工具调用超时。

接口依据：[AstrBot 官方工具注册源码](https://github.com/AstrBotDevs/AstrBot/blob/master/astrbot/core/star/register/star_handler.py)、[ToolSet 源码](https://github.com/AstrBotDevs/AstrBot/blob/master/astrbot/core/agent/tool.py)。

### 4. 自定义预设 `presets`（可添加多个）

点击 `+` 添加预设。每个预设条目包含：

| 配置项 | 说明 |
|--------|------|
| `trigger` | 触发词（如 `动漫化`），发送此词即触发该预设 |
| `model_trigger` | 指定使用的生图模型（填写该模型的文生图或图编辑触发词）。留空则使用第一个模型 |
| `llm_url` | 视觉语言模型 API 地址（OpenAI 兼容格式），如 `https://api.openai.com/v1`。也可填魔搭 LLM 地址 `https://api-inference.modelscope.cn/v1` |
| `llm_apikey` | 视觉语言模型的 API Key |
| `llm_model` | 视觉模型 ID，需支持图片识别，如 `gpt-4o`、`qwen-vl-max`、`Qwen/Qwen2.5-VL-72B-Instruct` |
| `preset_prompt` | 发给语言模型的指令，用于分析图片并生成改图提示词 |

预设工作流：用户发送触发词 + 图片 → 插件把图片和预设提示词发给 LLM → LLM 返回改图提示词 → 调用魔搭生图模型按原图比例出图。

## 用法示例

### 文生图

```
魔搭生图 一只可爱的边牧在草地上奔跑
魔搭生图 2:3 赛博朋克风格的城市夜景
魔搭生图 16:9 雪山日出
魔搭生图 1024x576 海边日落
```

格式：`触发词 [比例] 提示词`。比例可省略，省略时使用默认比例。

> 比例支持中英文冒号：`2:3` 与 `2：3` 均可。也可直接填像素值（如 `1024x576`）原样传给魔搭。

### 图编辑

```
魔搭改图 把这张图片变成油画风格  [附带图片]
魔搭改图 16:9 扩展画面背景  [附带图片]
```

格式：`触发词 [比例] 提示词 + 图片`。

- **注意**：魔搭仅图片编辑模型（如 `Qwen/Qwen-Image-Edit`、`Qwen/Qwen-Image`）支持 `image_url` 编辑，普通生图模型（如 `krea/Krea-2-Turbo`）会忽略输入图片。
- 魔搭的 `image_url` 只支持单张图片，插件会自动取第一张。
- 未指定比例时，自动检测原图比例并按最接近的支持比例生成。
- 可直接发送图片，或通过 **QQ 引用**某条含图片的消息作为输入。

### 自定义预设

预设支持两种模式，**两种模式都会经 LLM 优化提示词**后再生图：

**模式一：无图片 → LLM 优化提示词后文生图**（适用于文生图模型，如 Krea-2-Turbo）

```
krea2生图模板 3:4 生成一个可爱的女仆装写实风格女孩
```

此时不带图片，LLM 仅根据预设提示词 + 用户附加要求生成优化后的提示词，再传给生图模型。

**模式二：附带图片 → LLM 分析图片后生图**（适用于图编辑/改图模型）

发送预设触发词 + 图片即可：

```
动漫化  [附带图片]
```

也支持在触发词后空格附加额外说明，该说明会附加到预设提示词末尾一起发给语言模型：

```
动漫化 变成水彩画风格  [附带图片]
```

此时发给 LLM 的内容为：`<预设提示词>\n\n用户附加要求：变成水彩画风格`。

**自定义比例**：在触发词后第一个参数位置指定生成比例（不指定则按原图比例，无图时为 1:1）：

```
动漫化 4:3 变成水彩画风格  [附带图片]
krea2生图模板 16:9 生成一个可爱女孩
```

此时 `4:3` 不会传给 LLM，仅用于指定生图比例；`变成水彩画风格` 仍作为附加说明传给 LLM。

### 预设管理命令（命令行方式，非必须）

也可通过聊天命令管理预设（与 WebUI 配置等价）：

```
列出预设
添加预设 触发词|LLM地址|APIKey|模型ID|预设提示词
删除预设 触发词
```

示例：

```
添加预设 动漫化|https://api.openai.com/v1|sk-xxx|gpt-4o|分析这张图片并生成动漫风格的改图提示词
删除预设 动漫化
```

## 支持的比例

```
1:1  16:9  9:16  4:3  3:4  3:2  2:3
5:4  4:5  21:9  9:21  1:2  2:1
1:3  3:1  1:4  4:1  1:8  8:1
```

比例会自动转为像素 size（短边 1024，对齐到 8 的倍数）。不在列表中的比例也会按规则转换；直接填写像素值（如 `1024x1024`）则原样传给魔搭。

> 不同模型支持的尺寸范围不同，例如 FLUX 系列上限为 1024×1024，Stable Diffusion 3.5 上限为 2048×2048。若填写的尺寸超出模型范围，魔搭会返回错误。

## 常见问题

**Q：生成完成但没收到图片？**
A：部分 IM 适配器对图片发送有兼容性问题，插件已改用「下载到本地 → 从文件发送」的方式以提升稳定性。

**Q：图编辑提示「请附带至少一张图片」，但已发图？**
A：请确认图片已成功上传；若使用 QQ 引用，需引用一条含有图片的消息。

**Q：图编辑时提示生成失败？**
A：请确认使用的模型支持图片编辑（`image_url` 参数）。目前魔搭仅 `Qwen-Image-Edit` 等编辑模型支持，`krea/Krea-2-Turbo` 等纯生图模型不支持图编辑。

**Q：提示「提交失败(429)」？**
A：429 表示触发了魔搭的模型调用限流（每个模型有每日免费额度）。请等待额度恢复，或更换其他模型。

**Q：预设提示「语言模型未返回有效提示词」？**
A：通常是 LLM 返回空内容（可能拒绝处理或图片过大未读取）。插件已对图片自动压缩（超过 1024px / 1MB 时），请检查 LLM 配置和模型是否支持视觉。

**Q：提示「任务超时」？**
A：魔搭生图任务偶有排队，可适当调大模型的 `poll_timeout`（如 300 秒）。

**Q：比例转换后的尺寸被魔搭拒绝？**
A：不同模型支持的尺寸范围不同。请尝试改用 `1:1`，或直接填写模型支持的像素值（如 `1024x1024`）。

## 获取 API Key

前往 https://modelscope.cn/my/myaccesstoken 创建魔搭社区 Access Token（以 `ms-` 开头）。

## 与 Grsai 插件并存

本插件为独立插件（插件标识 `astrbot_plugin_modelscope`），与原 Grsai 插件（`astrbot_plugin_grsai`）互不影响，可同时安装在同一 AstrBot 中。两者区别：

| 项目 | 本插件（魔搭） | 原 Grsai 插件 |
|------|------|------|
| API 服务商 | 魔搭社区 ModelScope | Grsai |
| API Key | `ms-` 开头 Token | Grsai API Key |
| 模型 ID | `krea/Krea-2-Turbo` 等 | `nano-banana-2` 等 |
| 默认触发词 | `魔搭生图` / `魔搭改图` | `GPT生图` / `GPT改图` |
| 调用模式 | 异步轮询（固定） | 同步 / 异步可选 |
| 负向提示词 | 支持 | 不支持 |
| 分辨率 | 按像素 size | 1K/2K/4K 档位 |

> 注意：两个插件若使用相同的触发词会冲突，请确保各模型的 `trigger_t2i` / `trigger_i2i` 互不重复。
